# Multithreading Course — Java & Python

Support de cours HTML/CSS/JS modulaire sur le multithreading, la concurrence et les bonnes pratiques de conception.

## Contenu

- Introduction au multithreading
- Concepts fondamentaux de concurrence
- Java : bases et avancé
- Python : bases et avancé
- Synchronisation et coordination
- Bugs classiques
- Thread pools et exécution asynchrone
- Comparaisons : synchrone / async / threads / process
- Performance, debugging, observabilité
- Bonnes pratiques d’architecture
- Exercices et corrigés

## Utilisation

Ouvrir `index.html` dans un navigateur.

## Structure

Voir l’arborescence dans la page d’accueil du support.

## Objectif pédagogique

Monter progressivement de junior à avancé avec :
- définitions simples,
- analogies,
- exemples de code,
- comparaisons pratiques,
- cas réels d’entreprise,
- recommandations de senior / tech lead.
