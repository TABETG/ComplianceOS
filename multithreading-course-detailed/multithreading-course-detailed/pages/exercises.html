2. Lecture de code

class Counter {
    private int value = 0;

    public void increment() {
        value++;
    }

    public int getValue() {
        return value;
    }
}
  1. Ce code est-il thread-safe ? Pourquoi ?
  2. Propose deux corrections possibles.
from threading import Thread

items = []

def add_items():
    for i in range(1000):
        items.append(i)

threads = [Thread(target=add_items) for _ in range(4)]
for t in threads:
    t.start()
for t in threads:
    t.join()
  1. Quels risques ce code fait-il apparaître d’un point de vue général ?
  2. Que ferais-tu pour rendre le protocole plus robuste ?

4. Correction de deadlock

  • le problème,
  • une correction simple,
  • une correction architecturale meilleure si possible.

6. Mini cas d’architecture

Tu dois concevoir un service qui :

  • reçoit des fichiers,
  • les envoie à une API externe lente,
  • récupère les résultats,
  • effectue un calcul léger,
  • stocke en base.

Choisis entre synchrone, thread pool, async, queue interne ou process pool. Justifie.
