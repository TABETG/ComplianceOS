Performance, debugging et observabilité

Thread dumps, logs, métriques, profiling et méthodes réelles pour diagnostiquer les problèmes concurrents.

1. Diagnostic d’un bug concurrent

Un bug concurrent se manifeste souvent par : lenteur aléatoire, blocage, incohérence rare, thread qui ne s’arrête pas, CPU anormal, ou temps de réponse qui explose sous charge. Il faut donc observer le système à plusieurs niveaux.

2. Logs utiles

  • Nom du thread.
  • Identifiant de corrélation de la requête ou du job.
  • Entrée/sortie d’étapes critiques.
  • Durées, timeouts, échecs de lock, saturations de queue.
log.info("jobId={} thread={} start step=download",
         jobId,
         Thread.currentThread().getName());

3. Thread dump et blocages

En Java, un thread dump permet de voir l’état des threads : RUNNABLE, BLOCKED, WAITING, TIMED_WAITING. C’est souvent l’outil numéro un pour diagnostiquer deadlock, contention ou starvation.

  • jstack <pid>
  • jcmd <pid> Thread.print

Sur Python, on peut utiliser des traces, le module faulthandler, des dumps de stack et du profiling ciblé.

4. Profiling et contention

Le profiling permet de repérer :

  • temps passé à attendre des locks,
  • pools saturés,
  • threads trop nombreux,
  • code CPU chaud,
  • latences externes masquées par la concurrence.

Outils Java

  • JFR / Java Flight Recorder
  • VisualVM
  • Async-profiler
  • Micrometer + Prometheus + Grafana pour métriques

Outils Python

  • logging structuré
  • faulthandler
  • cProfile / py-spy selon contexte
  • métriques applicatives et traces

5. Bonnes pratiques d’observabilité

  • Expose le nombre de tâches en file.
  • Expose l’occupation des pools.
  • Mesure temps d’attente et temps d’exécution.
  • Détecte explicitement les timeouts et retries.
  • Définis des alertes sur saturation et backlog.

À retenir

  • Sans observabilité, un bug concurrent reste souvent une hypothèse.
  • Un thread dump bien lu vaut parfois plus qu’une heure de spéculation.
  • Mesurer la saturation des pools et des queues est indispensable en production.
