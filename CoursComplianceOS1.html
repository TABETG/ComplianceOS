2. Concept Clé : Row-Level Security (RLS)

Le multi-tenant ne se fait pas en créant une base de données par client, mais en utilisant une seule base où PostgreSQL filtre les lignes automatiquement selon le client connecté.

  • Sans RLS : Le développeur doit penser à ajouter WHERE tenant_id = X à chaque requête SQL. Risque d'erreur élevé.
  • Avec RLS : Le contexte de l'utilisateur est injecté dans la session de la base de données. SELECT * FROM factures ne renverra que les factures du client connecté, même si le développeur oublie la clause WHERE.
