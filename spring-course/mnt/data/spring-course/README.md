# spring-course

Support de formation HTML/CSS/JS sur Spring Boot, IoC/DI, AOP, `@Transactional`, Spring Data JPA, GraphQL avec Netflix DGS, Kafka et RabbitMQ.

## Arborescence

```text
spring-course/
├── index.html
├── pages/
│   ├── spring-boot.html
│   ├── ioc-di.html
│   ├── aop.html
│   ├── transactional.html
│   ├── jpa.html
│   ├── graphql-dgs.html
│   ├── kafka.html
│   ├── rabbitmq.html
│   ├── exercises.html
│   └── corrections.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── script.js
│   └── images/
└── README.md
```

## Utilisation

Ouvre `index.html` dans un navigateur.

## Objectif pédagogique

- Progression de junior à avancé
- Explications simples puis approfondissement technique
- Comparatifs utiles (Spring vs Boot, REST vs GraphQL, Kafka vs RabbitMQ, etc.)
- Exercices et corrigés séparés du cours
- Structure modulaire et maintenable
