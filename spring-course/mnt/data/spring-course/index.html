Support de formation technique

Spring Boot, IoC, AOP, transactions, JPA, GraphQL DGS, Kafka et RabbitMQ

Un cours progressif, professionnel et exploitable en formation interne, en révision d’entretien ou en auto-apprentissage. Chaque chapitre part des bases, monte vers les usages réalistes, puis va jusqu’aux pièges de production et aux recommandations senior.

Démarrer le cours Voir les exercices

Ce que tu vas maîtriser

  • Comprendre le conteneur Spring et la logique d’injection
  • Découper une application Spring Boot proprement
  • Éviter les pièges de @Transactional et JPA
  • Construire une API GraphQL avec Netflix DGS
  • Comparer Kafka et RabbitMQ avec des critères d’architecture
  • Passer du niveau junior au niveau avancé avec une vision production

Plan pédagogique

Progression proposée

1. Spring Boot

Différence Spring Framework / Spring Boot, starters, auto-configuration, profils, cycle de vie, structure d’application.

Lire le chapitre

2. IoC / Dependency Injection

Conteneur, beans, scopes, injections, ambiguïtés, architecture et recommandations de senior.

Lire le chapitre

3. AOP

Cross-cutting concerns, aspects, pointcuts, advices, limites, usages réalistes et pièges.

Lire le chapitre

4. @Transactional

Propagation, isolation, rollback, proxies, lazy loading, performance et découpage service/repository.

Lire le chapitre

5. Spring Data JPA

Entités, relations, repositories, projections, DTO, pagination, N+1, mapping et optimisation.

Lire le chapitre

6. GraphQL avec Netflix DGS

Schéma, queries, mutations, data fetchers, validation, pagination, batching et organisation projet.

Lire le chapitre

7. Kafka

Topics, partitions, consumer groups, idempotence, transactions, DLQ, monitoring et Spring Kafka.

Lire le chapitre

8. RabbitMQ

Exchanges, bindings, routing, ack/nack, retry, TTL, DLQ, Spring AMQP et comparaison avec Kafka.

Lire le chapitre

Méthode

Comment lire ce support

Junior

Comprendre les mots, le rôle des annotations et les exemples minimaux.

Intermédiaire

Relier les concepts à une vraie application et identifier les bonnes pratiques projet.

Avancé

Voir les limites, les comportements internes, les impacts performance et les arbitrages d’architecture.

Conseil de lecture : lis les chapitres dans l’ordre. Spring Boot, IoC et @Transactional forment le socle. Ensuite JPA, GraphQL et le messaging deviennent beaucoup plus simples à comprendre.
