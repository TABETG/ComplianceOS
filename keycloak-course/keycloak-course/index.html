Cours complet Keycloak 25 : de junior à expert

Ce support couvre la théorie utile, les décisions d’architecture, les pièges de sécurité et l’intégration concrète dans des applications modernes. L’idée directrice est simple : comprendre qui est l’utilisateur, comment il prouve son identité, ce qu’il a le droit de faire, puis comment industrialiser cela proprement.

Comment lire ce cours

Tu peux suivre les pages dans l’ordre ou aller directement sur un sujet précis. La logique pédagogique est la suivante :

Guide

Étape 1 : comprendre les fondamentaux IAM, sessions, tokens et trust.

Étape 2 : comprendre OAuth2, OIDC et SSO comme un flux complet.

Étape 3 : apprendre le modèle Keycloak : realm, client, user, role, flow.

Étape 4 : modéliser les rôles, brancher les applications et sécuriser la production.
