# Keycloak Course

Support HTML modulaire en français sur :

- Keycloak 25
- SSO
- OAuth2
- OpenID Connect
- FIDO2 / WebAuthn
- RBAC

## Structure

- `index.html` : page d'accueil
- `pages/` : chapitres
- `assets/css/style.css` : thème clair
- `assets/js/app.js` : navigation et mini interactions

## Utilisation

1. Ouvrir `index.html` dans un navigateur.
2. Naviguer page par page.
3. Adapter les exemples aux URLs, realms, clients et rôles de ton contexte.

## Choix pédagogiques

- montée progressive des concepts
- rappels fréquents
- exemples concrets
- code commenté sur les points importants
- orientation Java / Spring Boot quand utile
