# Multithreading Course

Support de formation modulaire sur le multithreading avec un focus principal sur Java et Python.

## Contenu
- fondements de la concurrence
- Java threading et concurrence avancée
- Python threading, GIL, multiprocessing et futures
- synchronisation et coordination
- race conditions, deadlocks et autres bugs classiques
- executors, pools et exécution asynchrone
- performance, debugging et observabilité
- bonnes pratiques d’architecture
- exercices et corrigés
