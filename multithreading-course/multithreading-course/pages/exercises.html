Exercices intermédiaires

3. Détection de bug concurrent

# Python
import threading

counter = 0

def increment():
    global counter
    for _ in range(10000):
        counter += 1

threads = [threading.Thread(target=increment) for _ in range(4)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print(counter)

Questions : quel bug peut apparaître ? Comment le corriger proprement ?
